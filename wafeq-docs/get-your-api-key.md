# Get your API Key

If you haven't done so already, create a free account on [wafeq.com](https://app.wafeq.com/accounts/signup/).

# Create a new API key

1. Log into your Wafeq account on [wafeq.com](https://app.wafeq.com/accounts/signup/)
2. Head over to the **API Keys** page in the **Developer** section on the left-side menu
3. Click **Create new key** and save your key.
4. Click the **Enable API** button to enable the API. If you cannot enable the API, make sure you're on the **Starter plan** at least.

You can now use your API Key to make API calls.

> 📘 You can use the API during free trials
>
> You need to be on the *Starter* plan to be able to use the API. The API can be enabled and fully used during free trials.
